# My Agent Skills

Portable backup of the skills available on this machine.

## Layout

- `skills/` contains each skill and its auxiliary files.
- `skills-manifest.json` records the original local path and SHA-256 for each `SKILL.md`.

## Notes

Managed plugin skills are copied as snapshots. Update the source plugins separately when you want newer versions. Runtime data, caches, logs, databases, and credentials are intentionally excluded.
