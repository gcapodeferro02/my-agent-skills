# Skill Selection Policy

Before starting every new user request:

1. Scan the local skill catalog.
2. Select the most relevant available skill or combination of skills.
3. Read and follow the selected skill instructions before acting, asking
   clarifying questions, or exploring files.
4. If no skill applies, proceed normally.
5. Do not invoke unrelated skills merely because they are available.

Prefer the installed skill copy when available. Use this repository's snapshot
as the fallback source. Managed plugins must retain their own installation and
activation workflow; runtime data, caches, logs, databases, and credentials
are not part of this catalog.
